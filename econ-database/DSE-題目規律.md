## 按概念

### 比較優勢：兩國生產同一物品的機會成本，是否落在 1 的同一邊？

兩國、兩種物品的數字題裡，常見排法是：兩國生產物品 X 的機會成本都大於 1，或者都小於 1。另一種物品因為是倒數，會落在另一邊。

對得上的選擇題：

| 題目 | 排法 |
| --- | --- |
| 2013 P1 Q38 | 兩國生產白米的機會成本都小於 1；生產電腦的都大於 1 |
| 2015 P1 Q40 | 兩國生產電腦的機會成本都小於 1；生產玩具的都大於 1 |
| 2017 P1 Q43 | 兩國生產玩具的機會成本都小於 1；生產手錶的都大於 1 |
| 2023 P1 Q42 | 兩國生產蘋果的機會成本都小於 1；生產桃子的都大於 1 |
| 2021 P1 Q43 | 乙國生產玩具和電腦的機會成本相等，都是 1。不是「都大於 1」或「都小於 1」 |
| 2025 P1 Q42 | 例外。X 國生產成衣的機會成本大於 1，Y 國小於 1 |

2026 P1 Q42 只有一個國家（1 工時生產物品 X、2 工時生產物品 Y），不屬於這個兩國比較。

### 本地居民總收入：這類題會不會問利息？

原猜想：由會考至 DSE 2026，類似題型都沒有問利息。

題庫裡的「從本地生產總值扣除」或「在本地生產總值加上」選擇題，選項是薪金、租金、股息、利潤、資本增益或費用，利息沒有出現。

| 題目 | 問法 | 利息 |
| --- | --- | --- |
| 2019 P1 Q25 | 要在 GDP 加上哪一項 | 選項沒有利息。答案 B，是居民從日本房屋收取的租金 |
| 2020 P1 Q25 | 應從 GDP 扣除哪一項 | 選項沒有利息。答案 A |
| 2022 P1 Q27 | 會從 GDP 扣除哪一項 | 選項沒有利息。答案 B，是非居民從香港公司收取的股息 |
| 2026 P1 Q24 | 應在 GDP 加上哪一項 | 選項沒有利息。答案 D，是香港廠商從印度工廠賺得的利潤 |

利息已經出現在另一種問法。2025 P1 Q24 問哪項不包括在香港的本地居民總收入，選項 C 是香港居民從政府銀色債券收取的利息。該題答案是 A，不是利息那項。

相關但不是同一題型：2015 P2 Q10 用外地足球員薪金比較 GDP 和 GNP；2018 P1 Q25、2023 P1 Q26 用表格比較本地生產總值和國民總收入或本地居民總收入。
