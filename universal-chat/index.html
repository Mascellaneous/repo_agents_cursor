    Poe 沒有公開的模型目錄 API，因此這份清單由你自己維護。 名稱需與 Poe 上的 bot 名稱完全一致（大小寫敏感）。 可一次貼上多個名稱（以逗號或換行分隔）。 「測試」會送出一句簡短提問，確認該模型能回覆。

    取樣參數

    越高越有創意，越低越穩定。

    Poe 供應商只會送出 temperature / top_p / max_tokens / stop，其餘參數會自動略過。

    若對話有自己的系統提示詞，會優先採用對話設定。

    數學公式

    可改成自架路徑（例如 vendor/katex/）以完全離線使用。

    支援的文字副檔名：txt / md / js / ts / json / html / css / py / java / c / cpp / cs / go / rs / rb / php / sql / yml / yaml / xml / csv / log / ini / sh 等。

    ☁️ GitHub 同步 選用

    不啟用也完全沒問題，資料一樣只存在本機。啟用後可跨裝置同步，並把歷史對話搬到 GitHub 備份。

    如何建立 Token（點開）
    1. 建立一個 Private repo，例如 my-chat-archive。
    2. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token。
    3. Repository access → Only select repositories → 只選剛剛那個 repo。
    4. Permissions → Repository permissions → Contents: Read and write（其他都不要給）。
    5. 設定到期日（建議 90 天），複製後貼到上方欄位。

    ⚠️ Token 會存在此瀏覽器。請勿在公用電腦啟用；務必使用 private repo 並只授權單一 repo。 匯出的備份檔永遠不會包含 Token。

    ⚠️ 進階／危險操作

    兩個「覆蓋」操作都需要打字確認，並且會 先自動備份（雲端 backups/ ＋下載一份到你的電腦）。

    ⇪ 檔案輸出 選用

    把 AI 回覆中的程式碼區塊一鍵 commit 到 GitHub——目的地可與聊天備份完全不同的 repo／分支／資料夾，並能在每個對話個別指定。

    Token 只存在本瀏覽器，永不寫入 IndexedDB、永不隨對話同步、永不進任何備份檔。
